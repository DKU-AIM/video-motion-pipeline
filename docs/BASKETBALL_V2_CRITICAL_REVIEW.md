# 농구 그라운딩 v2 발표 문서: 비판적 검토

2026-09-26 · 검토 대상: [발표 보고서](BASKETBALL_V2_PRESENTATION_REPORT.md)와 원본 48회 응답·실행 계획·추론 코드.

## 총평

**출력 행동과 구현 안정성을 조사한 예비실험으로는 동의한다. 정확한 다중 사건 검색 능력이나 모델 성능 순위를 입증한 연구로는 아직 부족하다.** 실행 예외 없이 48회 응답을 모으고 원문과 파서를 분리한 것은 유효한 성과다. 그러나 GT가 없으므로 다중 구간의 정답 여부, 누락, 오탐을 확인하지 못했다. 문서 제목·결론을 이 증거 수준에 맞추고, 부족한 평가 설계를 본문에 추가했다.

이번 보완은 문서와 저장된 결과의 재분석이다. 추가 모델 추론이나 진행 중 배치의 설정 변경은 하지 않았다.

|---|---|---|

## 2. 반드시 보완할 연구 설계

**가장 큰 공백은 정답 라벨이다.** 다섯 쿼리의 실제 사건 수·경계·길이·리플레이 여부를 모른다. 따라서 Precision/Recall/F1 수치를 추가하지 않았다. 본문 6.2와 6.5에 독립 검수, 애매한 사건, 일대일 매칭, 중복·범위 오류·잘림, 부재 쿼리의 평가 규칙을 제안했다. 규칙 제안과 실제 라벨링 완료를 구분한다.

**48회는 독립 표본 48개가 아니다.** 영상 1개에 관련된 쿼리 5개를 반복 적용한 조건 비교다. 모델 일반 성능 순위, 신뢰구간, 유의성 주장을 할 수 없다. 현재 영상에서 후보를 선정한다면 별도의 영상 검증이 필요하다.

**프롬프트 대조는 여러 요소가 묶여 있다.** 개수 지시만의 효과를 분리하려면 같은 시스템 메시지·JSON 형식·부재 규칙·출력 상한을 유지하고 단일/모든 구간 요청만 바꾸는 신규 대응 실험이 필요하다. 단일 사건 지시를 다중 사건 Recall로 불공정하게 순위화하지 않는다. 이 추가 실험은 현재 배치 범위에 넣지 않았다.

**FPS와 공간 정보가 결합돼 있다.** 현재 40회 설계는 고정 예산에서 시간/공간 배분의 실용적 비교로 해석한다. 순수 FPS 효과를 주장하려면 별도로 프레임당 해상도를 고정해야 한다. 실제 프레임·시각·크기 기록도 필요하다. 현재 별도 실행기의 고정 A→B→C→D 순서를 무작위 실행으로 표현하지 않도록 수정했다.

**어려운 부재 질문이 부족하다.** 농구 영상에 축구 골이 없다는 질문 하나만으로 환각 억제를 평가할 수 없다. 유사 동작·유니폼 속성 등 가까운 혼동 사례를 전체 검수 후 추가한다. 실제 등장하는 질문을 음성 정답으로 만드는 실수를 피한다.

## 4. 자원 분석과 재현성 검토

현재 비용 표는 동일 서버에서 관찰한 서비스 지연에 유용하다. 그러나 출력 길이·빈 응답·입력 토큰·워밍업 차이가 있으므로 모델 고유 계산 효율 순위로 일반화하지 않는다. 같은 쿼리별 지연과 출력 길이, 정답 회수량을 함께 비교하는 것이 다음 단계다. GPU peak allocated는 전체 보드 메모리나 에너지 소비가 아니다.

실행 당시 코드 해시와 현재 파일을 비교했다. `basketball_probe.py`와 `vtg_run.py`는 일치하여 사본을 보존했고, `basketball_batch.py`는 변경돼 당시 원본으로 보존하지 않았다. 전체 코드 재현이 완료됐다고 표현하지 않는다. [보존 범위](analysis/basketball_v2/verified_source_snapshot/README.md)를 명시했다. 다음 실행부터 모델 revision의 사전 고정과 전체 소스·의존성 사본이 필요하다.

## 5. 발표에서 예상되는 질문

- **그래서 어떤 모델이 가장 잘하나요?** 현재는 정확도 순위를 모른다. 안정성과 비용을 기준으로 후속 후보를 정했으며 GT 평가가 남아 있다.
- **여러 구간을 쓸 수 있으면 다중 그라운딩 아닌가요?** 출력 형식 능력과 영상에 맞는 사건 회수는 별도다. 중복·누락·오탐을 일대일 정답 매칭으로 검증해야 한다.
- **왜 Qwen의 반환 수가 많은데 좋다고 하지 않나요?** 연속 구간을 규칙적으로 나눈 출력이나 영상 밖 예측이 포함된다. 구간 개수만으로 정답 회수량을 알 수 없다.
- **FPS를 올리면 좋아지나요?** 아직 가설이다. 고정 예산에서 공간 정보 손실과 시간 정보 증가가 교환될 수 있다.
- **이 결과를 다른 경기에도 적용할 수 있나요?** 일반화는 미검증이다. 현재 영상은 탐색용이고 별도 영상 평가가 필요하다.

## 6. 반영 완료와 남은 일

**반영 완료:** 주장 수준 조정, 실행/형식/복구/의미 정확도 분리, 독립 표본과 지시문 교란 명시, 추가 구조 진단, FPS 해석 수정, 라벨·평가·실패 처리 프로토콜, 재현성 보존 범위 명시, HTML 재생성.

**자료가 없어 미완료:** GT 작성·검수, 의미 정확도 계산, 사건 사례별 정답 대조, 다른 영상 일반화, 독립적인 프롬프트 효과 검증, 반복 속도 측정. 이를 완료한 것처럼 결과를 채우지 않았다.

발표 결론은 “여러 시간 쌍을 생성하는 모델은 여럿이지만, 실제 다중 사건 회수는 아직 검증해야 한다”가 현재 증거에 가장 잘 맞는다.
