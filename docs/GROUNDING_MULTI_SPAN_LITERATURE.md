# 모델별 다중 구간 출력 근거 조사

조사일: 2026-09-26. 대상: 실험한 8개 모델. 논문 원문·공식 모델 카드·저자 코드만 판단 근거로 사용했다. 진행 중인 실험 설정은 변경하지 않았다.

## 구분해야 할 세 질문

1. 텍스트 응답에 시간 구간을 여러 개 표현할 수 있는가?
2. 한 쿼리에 여러 정답 구간이 있는 과제를 명시적으로 학습·평가했는가?
3. 기본 예제의 프롬프트·후처리가 여러 구간을 보존하는가?

단일 구간 기본 예제는 다중 구간 생성 불가능의 증거가 아니다. 여러 구간 출력도 정확도와 완전한 회수를 보장하지 않는다. 단일 구간과 시간순 첫 구간은 서로 다르며, 아래 문헌에서 모든 모델이 첫 발생만 선택하도록 보장한다는 근거는 확인하지 못했다.

## 모델별 판정

| 실험 모델 | 확인된 내용 | 해석 |
|---|---|---|
| TimeLens2-4B / 8B | 단일·다중 구간을 학습 데이터와 구간 집합 목적에 명시 | 다중 구간이 명시적 설계 대상 |
| TimeLens-8B | 자체 기본 예제는 단일 구간. 후속 TimeLens2 논문에서 다중 구간을 반환하는 라벨링 모델로 사용 | 기본 예제와 실제 출력 가능성을 분리해야 함 |
| TimeLens-7B | 기본 모델 카드가 시작·종료 한 쌍을 요청 | 공식 다중 구간 학습/평가 근거는 이번 조사에서 미확인. 불가능을 뜻하지 않음 |
| Time-R1-3B / 7B | 단일 예측 구간과 정답 구간의 보상, 최종 answer 한 쌍 | 기본 연구 설정은 단일 구간 중심. 생각 과정의 여러 시각은 최종 다중 답과 다름 |
| Qwen3-VL-8B-Instruct | 텍스트 타임스탬프 및 영상 시공간 grounding 데이터 | 범용 영상 모델. 해당 8B의 모든 반복 사건 회수 성능에 대한 명시적 근거는 미확인 |
| Qwen2.5-VL-7B-Instruct | 동적 FPS·절대 시간 정렬, temporal grounding 평가 | 범용 영상 모델. 다중 구간 전용 학습/회수 보장으로 해석할 수 없음 |

## 중요한 1차 자료

### TimeLens2

논문 §3.1은 93,232개 예제 중 12,091개가 복수의 supporting interval을 가진다고 설명한다. §3.2는 구간 집합 학습과 다양한 응답 형식을 설명한다. 따라서 단순히 JSON 프롬프트만 바꾼 모델로 이해하면 안 된다. [논문](https://arxiv.org/html/2607.17423v1#S3), [공식 저장소](https://github.com/MCG-NJU/TimeLens2).

특히 §3.1의 Dual-agent local grounding에서는 **TimeLens-8B와 Qwen3-VL-30B-A3B가 짧은 제안 클립마다 하나 이상 구간 또는 빈 집합을 반환**한다고 명시한다. TimeLens-8B의 다중 구간 출력 사용 사례다. 이 결과를 Qwen3-VL-8B에 그대로 옮겨 주장하거나 전체 경기 영상의 완전 회수를 보장한다고 해석하면 안 된다. [해당 절](https://arxiv.org/html/2607.17423v1#S3.SS1).

### TimeLens

논문 §3.1은 출력 S를 시작·종료 한 쌍으로 정의하고, 정답 구간 바깥에 같은 쿼리를 만족하는 사건이 없어야 한다는 주석 기준을 제시한다. §3.2는 반복 사건 등의 문제를 쿼리 수정이나 새 사건 선택으로 정제한다. 이 설정은 농구의 모든 반복 슛을 찾는 과제와 다르다. [논문 §3](https://arxiv.org/html/2512.14698v1#S3).

7B·8B 공식 추론 예제 역시 시작·종료 한 쌍 형태를 요청한다. 이것은 출력 개수를 구조적으로 한 개로 제한한다는 증거가 아니다. [8B 모델 카드](https://huggingface.co/TencentARC/TimeLens-8B), [7B 모델 카드](https://huggingface.co/TencentARC/TimeLens-7B).

### Time-R1

논문 §3.2의 보상은 예측 구간 한 쌍과 정답 한 쌍의 관계를 사용하며, 최종 answer도 한 쌍 형태다. 공식 demo.py는 중간 분석의 시각들과 최종 답을 구분한다. 3B의 cold-start 설명은 있지만 그것이 다중 사건 검색 학습의 근거는 아니다. [논문](https://arxiv.org/html/2503.13377v3#S3.SS2), [공식 demo.py](https://github.com/xiaomi-research/time-r1/blob/main/demo.py).

### Qwen

Qwen3-VL 보고서 §2.3, §3.2.7은 텍스트 타임스탬프와 영상 학습 데이터를 설명한다. Dense captioning은 여러 사건을 설명하는 과제이며, 단일 쿼리의 모든 발생을 회수하는 것과 동일하지 않다. [Qwen3-VL 보고서](https://arxiv.org/html/2511.21631v1).

Qwen2.5-VL 보고서 §2.1.2–3, 영상 이해 평가 부분은 동적 FPS, 절대 시간 정렬과 Charades-STA grounding을 설명한다. 이번에 확인한 부분에서는 7B를 다중 구간 전용 모델이라고 판정할 근거를 찾지 못했다. [Qwen2.5-VL 보고서](https://arxiv.org/html/2502.13923v1), [공식 소개](https://qwenlm.github.io/blog/qwen2.5-vl/).

## 팀 실험에 적용할 결론

- TimeLens2가 다중 구간을 명시적으로 겨냥했다는 설명은 문헌과 부합한다.
- TimeLens2만 여러 구간을 출력할 수 있다는 보편적 주장은 TimeLens-8B의 문헌상 사용 사례와 맞지 않는다.
- 동료의 단일 출력 관찰은 당시 기본 지시·파서·출력 상한에 대한 관찰일 수 있다. 의도나 정직성은 이 자료로 판단할 수 없다.
- 우리의 all-json 결과는 출력 가능성 관찰이며, 공식 기본 설정 재현 성능과 분리해 보고한다.
- 사용자 목적은 올바른 모든 사건의 회수다. GT를 기준으로 Precision/Recall, 중복·누락, 부재 오탐을 평가해야 한다. 많이 출력한 것만으로 채택하지 않는다.
