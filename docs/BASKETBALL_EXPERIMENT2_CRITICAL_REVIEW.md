# 실험2 보고서의 주장·계산 검토

대상: `BASKETBALL_EXPERIMENT2_PRESENTATION_REPORT.html`. 실험1의 비판적 검토 원칙을 이어받아 같은 분석 작업 안에서 자체 점검했다. 독립 연구자 검수나 GT 라벨링을 수행한 것은 아니다.

| 주장/위험 | 점검 결과 |
|---|---|
| 40회 모두 성공했으므로 정확하다 | 실행 성공·구문 준수·유효 범위와 의미 정확도를 분리. GT 점수 없음. |
| FPS만의 순수 효과 | 부정. 실제 격자가 A [55,36,64] → C [222,18,32]로 변해 시간/공간 배분이 함께 바뀜. |
| 실제 샘플 장수·해상도를 직접 기록했다 | 부정. 격자와 해당 모델 config의 temporal patch/spatial patch로 환산한 값이라고 표시. 실제 시각 목록은 없음. |
| 비주얼 예산을 늘리면 Recall 향상 | 근거 없음. 반환 수 변화만 관찰; GT의 사건 수와 경계를 모름. |
| 예측 Jaccard가 정확도 | 부정. 두 조건의 예측 합집합 간 일치도이며 빈/빈은 undefined로 처리하고 그림에서 제외. |
| 속성 밖 비율 0%면 정답 | 부정. 일반 슛을 전체 영상으로 출력해도 0%가 될 수 있음. |
| TL2 B/C가 앞 36초만 입력받았다 | 부정. 앞부분에 예측이 집중됐다는 사실만 서술. 입력 누락이나 후반 실제 사건의 누락 여부는 미확인. |
| 구간 30개면 같은 출력 | 부정. TL8 C/D는 개수는 같으나 합집합 130/95초, 연결 성분 29/30으로 다름. |
| 2048 출력 상한의 개선 효과 | 입증하지 못함. 이번 최장 출력은 422토큰으로 512 미만. |
| D와 실험1 비교 가능성 | 같은 입력 해시·프롬프트·모델 commit, 10쌍 원문/구간/격자/입력 토큰 일치 확인. 일반 결정성 주장 없음. |
| 시간 표의 점은 반복/신뢰구간 | 아님. 서로 다른 쿼리 5개. 고정 순서·첫 호출 효과를 명시. |
| GPU 사용률/전력 수치 | MIG 사용률 숫자 없음. 물리 GPU 전력을 해당 프로세스의 에너지로 환산하지 않음. |
| 실행 소스 재현 | 계획에 기록된 세 파일 해시 일치 사본 저장. 컨테이너 전체 재현은 미보장. |

주요 수치는 `docs/analysis/basketball_parameters/`의 JSON/CSV로 재계산할 수 있다. 원본 추론 결과는 수정하지 않았고 새 추론을 실행하지 않았다. 입력·결과·자원 로그·실행 코드 사본은 출처와 해시를 함께 보관했다.

남은 일: 전체 영상의 독립 GT 검수, 정답과의 일대일 사건 평가, 실제 샘플 시각 기록, 동일 조건 반복과 실행 순서 통제, 다른 경기 영상의 일반화 확인.
