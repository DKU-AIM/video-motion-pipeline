# 엘리스 새 인스턴스 검증 · 2026-09-18

## 환경과 범위

새 Ubuntu 22.04.5 / Python 3.10.14 / NVIDIA A100X MIG 2g.20gb / 드라이버 580.173.02에서 시스템 패키지와 세 Python 가상환경을 생성했습니다. 기존 서버의 가상환경을 복사하지 않았습니다. SMPL 자산과 기존 기준 모션 특징은 별도로 복원했습니다.

설치 중 확인한 두 문제를 반영했습니다.

- Anny 0.6.0은 roma 1.5.7 이상을 요구하므로 roma 버전을 1.5.7로 수정.
- 새 서버의 PyRender import에 GLU 시스템 라이브러리가 필요하여 `libglu1-mesa` 추가. 이후 OSMesa 실렌더링 통과.

## 해석할 때 구분할 점

이 검증은 **새 인스턴스에서 설치하고 결과를 생성할 수 있는지**를 확인합니다. 캡션의 정확도를 입증하지 않습니다. 예를 들어 농구 장면에서 `a person lifts a dumbbell with his right hand.`와 같은 설명이 나왔습니다. 출력이 생성되었다고 올바른 어노테이션으로 사용하면 안 됩니다.

샘플은 기존 농구 클립의 앞 3초를 축소한 원본/크롭 조건입니다. 다인 장면이며 기존 exporter가 긴 트랙을 자동 선택했습니다. 원하는 선수 한 명의 정답 캡셔닝을 검증한 사례는 아닙니다. 입력 영상, 사람이 확인한 대상 ID, 결과 모션과 캡션의 일치를 별도로 검수해야 합니다.

- 실제 그라운딩 GPU 테스트는 TimeLens2-4B 한 모델입니다. TimeLens-8B 등 모든 변형에 대한 실추론 검증은 아닙니다.
- 3초 샘플의 설치·실행 확인이며 긴 영상의 메모리 사용량/성능 보장은 아닙니다.
- 공식 외부 모델 내부에서 받는 DINOv3/Anny 추가 자료와 HF 가중치 전체가 고정된 오프라인 패키지는 아닙니다.
- 기존 MotionGPT 입력 변환의 좌표·리타게팅 및 대상 선정 한계는 그대로입니다. 이번 변경은 환경 구축과 실행 실패 처리에 집중했습니다.
- SSH 주소·키, 영상·SMPL·모델 가중치는 팀 레포에 넣지 않았습니다.
