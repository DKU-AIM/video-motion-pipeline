# 후보 2: 영상 기반 VLM 설명 생성

아직 실행 모델과 구현이 선정되지 않은 비교 후보입니다. 이 폴더에는 추론 코드가 없습니다.

입력은 대상 인물 식별 정보가 있는 RGB 클립입니다. 출력은 해당 인물의 동작 설명이며 clip_id, track_id, 원본 시간 구간과 함께 저장하도록 설계합니다.

비교 시 같은 구간·같은 인물을 사용하고 행동 일치, 인물 일치, 시간 순서와 근거 없는 설명을 검수합니다. 영상에서 보이지 않는 정보를 추측하지 않도록 하고, 생성 설명은 검수 전 GT로 취급하지 않습니다.

모션 캡셔닝과 비교 후 하나의 설명 생성 방식을 정합니다. 두 경로를 모두 실행하는 확정 파이프라인이 아닙니다.
